# Job Data Collection Using APIs

## Project Overview

This project demonstrates how Python can be used to collect job market data through APIs and organize the retrieved information for analysis.

The project was completed as part of my Python and Data Analysis learning through the IBM Data Analyst Professional Certificate on Coursera.

## Skills Demonstrated

- Python
- REST APIs
- HTTP Requests
- JSON Data
- Data Collection
- Data Processing
- Pandas
- Data Analysis

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- Requests
- APIs

## Project Workflow

1. Connected to an API using Python.
2. Retrieved job-related data.
3. Processed API responses.
4. Extracted relevant job information.
5. Organized the collected data for further analysis.

## What I Learned

This project helped me understand how APIs can be used as a real-world data source and how Python can automate the process of collecting structured data for analysis.
